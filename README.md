# Hikari Secretary Mini App

Будущий Telegram Mini App для администраторов Hikari Secretary. Он заменит
ограниченные административные таблицы и навигацию внутри чата с ботом на
адаптивный интерфейс внутри Telegram.

## Назначение

- управление мероприятиями, регистрациями, публикациями и отзывами;
- таблицы со скрываемыми колонками, сортировкой и удобным просмотром данных;
- единая вёрстка на телефоне и в Telegram Desktop;
- авторизация через Telegram Mini App и API бэкенда.

## Границы

Mini App — клиентское приложение, а не владелец данных. Оно не подключается к
PostgreSQL напрямую и не содержит бизнес-правила: данные и разрешения получает
только через API `hikari-secretary-backend` после проверки Telegram `initData`.

## Планируемая структура

```text
src/            # интерфейс, экраны и клиент API
public/         # статические ресурсы
deploy/         # Dockerfile и конфигурация раздачи
```

Репозиторий пока содержит только стартовую документацию. Реализация начнётся
после подготовки API-контракта бэкенда и UX-плана административной панели.
